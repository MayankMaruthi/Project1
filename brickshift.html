BrickShift

Build Beyond the Box.

BrickShift gives building sets a new life. Users select the sets they already own and the app generates completely new vehicles that can be built using only those existing pieces.

Instead of building one model and leaving it on a shelf, the same pieces can become a supercar, race car, truck or another completely new creation.

How does it work?

1

Select Your Sets

Enter or scan the building sets you already own.

2

Choose a Vehicle

Choose what type of new vehicle you want to create.

3

Generate Design

The app designs something new using only your available pieces.

4

Build It

Follow the generated step-by-step instructions.

Select Sets → Choose Vehicle → Generate → Build
